## Embedded Systems Project Report: [ThermoGuard AC]

## 1. Introduction
This repository provides the detailed software design for the "Automotive Air Conditioning Control Panel" (ThermoGuard) project. This system is developed for the AVR ATmega328P microcontroller as part of the KH5023FTE Embedded System Design & Development module.

The system has been extended in v2.0 with three additional features: AI-driven occupancy control using computer vision (OpenCV), hands-free voice control via speech recognition, and a PIR motion sensor for automatic LCD backlight wake-up.
